## 2. 配置契约

当前配置 schema 版本为 `1`。JSON 使用 camelCase 字段名和字符串枚举，颜色使用 `#RRGGBBAA`。图片内容不写入配置 JSON，只通过 `AssetReference` 的 GUID、媒体类型、大小和 SHA-256 引用。

`.epsx` 包包含：

```text
manifest.json
profiles.json
assets/<guid>.png
assets/<guid>.svg
```

导入流程先完整读取和校验 ZIP、JSON、资源大小与哈希，再执行纯函数式合并。主配置、备份配置和已有运行时快照不会在失败导入时被部分更新。

## 3. 当前限制

- 当前 schema 只实现版本 `1`；未知更高版本会拒绝，缺少 `schemaVersion` 的旧数据按版本 `0` 迁移。
- EPSX 只接受 PNG 和静态 SVG 的资源元数据；SVG 内容的脚本、外部引用和复杂度检查在图像渲染阶段继续完成。
- 同名 Profile 或 ProfileSet 允许并存，界面层需要在导入确认时展示名称冲突。
- `ConfigurationMerger` 返回新文档和资源列表，调用方负责将合并结果提交到持久化存储和 Host 快照。
