## 人工验证

需要在真实 Windows 桌面完成：

1. 在 100%、150% 和 200% 显示缩放下逐页检查文字截断、控件重叠和滚动区域。
2. 分别切换浅色、深色和系统主题，检查输入框、列表选择、错误条和预览区域可读性。
3. 拖动准星滑块，确认 Avalonia 预览与 Host 覆盖层同步且无明显延迟。
4. 导入 PNG 和静态 SVG，确认 Host 最终渲染与资源元数据一致。
5. 捕获、冲突和清除快捷键，确认 Host 注册状态符合 UI。
6. 关闭 UI，确认 Host、托盘和当前覆盖层继续运行。

## 已知契约缺口

配置 Schema v1 和 Host 当前未定义以下字段，因此阶段 7 UI 不写入私有扩展：

- 开关开启/关闭的自定义提示文案；
- 上一个/下一个配置集快捷键；
- 上一个/下一个配置快捷键。

这些能力必须在 Core Schema、迁移、Host 解析和 IPC 测试同步扩展后再加入 UI。
