# 阶段 1 覆盖引擎验证记录

## 1. 验证范围

阶段 1 已实现以下原型能力：

- 每个枚举显示器创建独立覆盖 HWND；
- `WS_EX_TOPMOST`、`WS_EX_TOOLWINDOW`、`WS_EX_NOACTIVATE`、`WS_EX_TRANSPARENT`、`WS_EX_LAYERED` 和 `WS_EX_NOREDIRECTIONBITMAP`；
- Direct3D 11、Direct2D、WIC 和 DirectComposition 初始化；
- 每个显示器独立的 composition swap chain 和 visual；
- 透明背景、中心点、四支臂和嵌入式透明 PNG；
- 焦点显示器模式与全部显示器模式；
- `WM_DISPLAYCHANGE`、`WM_DPICHANGED`、`WM_DEVICECHANGE` 触发的显示器重建；
- `EVENT_SYSTEM_FOREGROUND` 前台窗口变化监听；
- 事件驱动渲染，静止状态不持续提交帧；
- 进程 CPU、工作集、私有字节和 Present 延迟 CSV 记录；
- `--smoke-test`、`--diagnostics-seconds` 和 `Ctrl+Shift+F12` 退出路径。

本记录不代表 DX9/DX11/DX12/Vulkan/OpenGL 游戏兼容性已经全部验收。游戏和反作弊环境必须通过人工矩阵逐项验证。

## 2. 运行命令

在仓库根目录运行：

```powershell
.\build\native\windows-debug\src\ExternalPeepSight.Host\Debug\ExternalPeepSight.Host.exe --focus-monitor
.\build\native\windows-debug\src\ExternalPeepSight.Host\Debug\ExternalPeepSight.Host.exe --all-monitors
.\build\native\windows-debug\src\ExternalPeepSight.Host\Debug\ExternalPeepSight.Host.exe --diagnostics-seconds=60 --metrics-output=artifacts\stage1\metrics.csv
```

原型模式使用 `Ctrl+Shift+F12` 退出。CTest 使用 `--smoke-test`，默认运行约 1.5 秒后退出。

## 5. 当前技术结论

1. DirectComposition 与 `WS_EX_LAYERED`、整窗 alpha 在当前 Windows 11 环境下可以同时保持视觉合成。
2. 仅依赖 `WS_EX_TRANSPARENT` 或 `HTTRANSPARENT` 不足以证明跨进程点击穿透，因此原型保留 Layered Window 样式和运行时命中测试。
3. 阶段 1 的实现和本机自动化验证已完成。
4. 混合 DPI、负坐标、真实游戏窗口、Vulkan/OpenGL、HDR 和 Windows 10 仍属于发布前人工验证项。
5. 如果目标矩阵中出现点击穿透或层级回归，应切换到只覆盖准星包围盒的小尺寸 Layered Window 回退路线。
