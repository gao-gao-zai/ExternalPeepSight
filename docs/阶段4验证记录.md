# 阶段 4 验证记录

## 1. 验证范围

本阶段打通 UI 与原生 Host 的 IPC 和进程生命周期，范围包括：

- 版本化 Named Pipe JSON 协议；
- 当前用户安全边界、远程客户端拒绝和随机端点；
- Hello Token、请求幂等、配置版本顺序和 Ack/Error；
- UI 启动 Host、断线重连和状态重新同步；
- UI 关闭后仅断开连接，不要求 Host 退出；
- Host 单实例、通知区域图标、打开设置和退出命令。

当前 UI 生命周期接入基于仓库中的 WPF 骨架。`HostClient`、端点发现和进程管理服务不依赖 WPF，可在后续 Avalonia 迁移中直接复用。

## 2. 实现结果

### 2.1 协议与状态

- 协议版本固定为 1，信封包含 `protocolVersion`、`requestId`、`type` 和 `payload`。
- 单条 UTF-8 JSON 消息最大 1 MiB，最大嵌套深度为 64。
- `requestId` 必须为 UUID；相同请求与内容返回缓存响应，不同内容复用同一 ID 会被拒绝。
- `Hello` 必须是连接上的第一条消息，Token 使用 32 字节系统随机数的小写十六进制表示。
- `configurationVersion` 限制为 1 至 `9007199254740991`。
- 新版本覆盖旧版本；相同版本和相同内容幂等；旧版本和版本冲突均返回 Error。
- Host 状态独立于客户端连接保存，重连后通过 `GetState` 恢复。

### 2.2 管道安全与端点发现

- 管道使用消息模式、异步 I/O 和 `PIPE_REJECT_REMOTE_CLIENTS`。
- DACL 只允许 `SYSTEM` 和当前用户访问。
- 每次 Host 启动生成随机 Pipe 名和握手 Token。
- `%LOCALAPPDATA%\ExternalPeepSight\host-<instance>.endpoint` 通过临时文件和原子替换发布。
- Host 正常退出前原子发布同实例、同 PID 的 `.shutdown` 标记；异常退出不写标记。
- UI 校验协议版本、实例命名空间、Token、PID 和 Host 进程存活状态。
- 实例 ID 仅允许 ASCII 字母、数字、`-` 和 `_`，最大长度 64。

### 2.3 UI 与 Host 生命周期

- 普通 UI 启动允许发现或拉起 Host，并使用指数退避重连。
- UI 启动 Host 时传递自身路径，Host 托盘可在非相邻开发目录中重新打开设置。
- 托盘启动 UI 时使用 `--connect-existing`，不会因短暂发现失败递归启动 Host。
- UI 重连后先完成 Hello，再读取 Host 当前状态。
- UI 发现正常退出标记后停止重连并退出，不会把托盘 `Exit` 误判为 Host 崩溃；下一次普通 UI 启动会清除旧标记并重新启动 Host。
- 响应信封、字段集合、类型、消息长度和 JSON 深度均在 UI 端再次校验。
- 请求取消或连接失败会从 pending 表移除并唤醒等待方。
- UI 退出只释放 Named Pipe；Host 的退出由托盘命令、现有退出热键或自身错误处理控制。

### 2.4 Host 托盘与单实例

- Host 通知区域菜单提供 `Open settings` 和 `Exit`。
- 双击图标打开设置，Explorer 重建任务栏后重新注册图标。
- 控制窗口销毁时先移除通知区域图标。
- 每个实例命名空间使用当前用户可访问的本地互斥量，第二个 Host 不会进入运行循环。

## 3. 自动化覆盖

### 3.1 托管测试

新增 `ExternalPeepSight.UI.Tests`，覆盖：

- 合法、重复字段和错误实例命名空间的发现文件；
- 非 ASCII 和非法实例 ID；
- JSON 精确整数范围；
- 客户端重复启动；
- Hello、GetState、ApplySnapshot；
- 服务端断开后的自动重连和状态重新同步；
- 正常退出标记的 PID 校验、清理和停止重连；
- UI 客户端释放后服务端观察到连接关闭，而不是退出命令。

Release 定向预验证结果：UI 13 项通过。

### 3.2 原生测试

新增或扩展测试覆盖：

- 未握手命令和错误 Token；
- 未知协议版本、过深 JSON、未知字段和超范围整数；
- 重复 `requestId`、幂等请求、旧版本和版本冲突；
- 断开重连后的 Host 状态恢复；
- 远程客户端拒绝、消息模式和当前用户 DACL；
- 并发第二连接、损坏帧、超大长度声明；
- 停止时取消挂起的 Connect/Read/Write；
- 单实例互斥量、随机小写十六进制 Token 和正常退出标记。

Release 定向预验证结果：CTest 36 项全部通过。
