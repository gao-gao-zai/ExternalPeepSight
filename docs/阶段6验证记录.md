# 阶段 6 完整渲染能力验证记录

## 1. 实现范围

阶段 6 已实现：

- 中心点颜色、半径和可见性；
- 四支臂独立角度、间隔、长度、宽度、颜色和可见性；
- C# 预览与 C++ Host 共用 Golden Fixture 的物理像素几何；
- 按实际准星或图片内容动态计算的小尺寸覆盖 HWND；
- PNG 大小、尺寸、路径和 SHA-256 校验，以及 WIC 纹理缓存；
- 静态 SVG XML 校验、脚本和外部引用拒绝，以及 Direct2D SVG 文档缓存；
- 图像锚点、偏移、统一缩放和宽高比选项；
- DirectWrite Toast 字体、位置、持续时间、优先级和去重；
- UI 侧约 16 ms 的快照更新合并；
- 配置发布前的 CPU/GPU 资源预构建；
- 设备丢失后根据不可变快照重建图片缓存。

资源目录由 UI 使用 `--assets-root` 显式传给 Host。Host 不从当前工作目录猜测资产位置。

## 2. 原子更新与缓存

配置应用顺序为：

```text
解析输入与渲染配置
  -> 校验资源路径、大小、SHA-256、PNG/SVG 结构
  -> Render 线程预构建 WIC Bitmap 或 D2D SVG Document
  -> 应用输入注册
  -> 发布不可变 HostSnapshot
  -> 重建紧边界 HWND 和 composition surface
  -> IPC Ack
```

任何资源预构建失败都会返回错误，不推进 IPC 配置版本，也不替换当前窗口和画面。渲染循环只使用快照中保存的编码字节和设备级缓存，不在绘制时读取文件。
