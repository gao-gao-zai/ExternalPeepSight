## 2. 实现结果

### 2.1 输入线程与后端选择

- Input 线程拥有独立隐藏 HWND，并在该线程上创建和释放 Raw Input、WTS 会话通知、低级键盘钩子和系统热键。
- 设置默认使用 Raw Input：无修饰键的 Toggle/独立开关键以及所有 Hold 绑定进入 Raw Input，带修饰键的 Toggle/独立开关键进入 `RegisterHotKey`。
- 设置切换为低级钩子后，鼠标绑定由 `WH_MOUSE_LL` 处理，键盘绑定由 `WH_KEYBOARD_LL` 与约 12 ms 周期的 `GetAsyncKeyState` 采样共同处理，带修饰键的键盘绑定不再依赖 `RegisterHotKey`。兼容后端接受云客户端标记为 injected 的输入；采样覆盖主键及要求的左右物理修饰键。
- Raw Input 模式保留低级键盘钩子和约 12 ms 周期的 `GetAsyncKeyState` 采样作为裸键、Hold 与脚本绑定的冗余来源，兼容仅提供鼠标输入或截断本机键盘钩子链的云电脑客户端。
- Raw Input 与低级钩子归为事件捕获来源，轮询作为独立来源。每个物理键只有在合并按下状态变化时才进入 Toggle、Hold 和脚本状态机；轮询的瞬时未按下不会抵消捕获来源的 KeyDown，重复捕获 KeyDown 也不会反复触发 Toggle。
- 前台窗口变化后延迟刷新 `WH_KEYBOARD_LL`，使 Host 在远控客户端完成前台初始化后重新进入键盘钩子链首，并恢复可能被系统静默移除的低级键盘钩子。
- Raw Input 使用 `RIDEV_INPUTSINK | RIDEV_DEVNOTIFY`；低级钩子用于兼容云桌面等可能接管前台 Raw Input 的应用。
- 后端切换会清空已按下的物理键和活动 Hold；Raw Input 注册失败时自动回退到低级钩子。
- 设置页提供管理员输入兼容模式。Host 在发现记录中发布实际提升状态，UI 通过认证后的 `RestartHost` 命令完成普通权限与管理员权限切换；UAC 取消后不会循环弹出授权窗口。
- 输入回调只更新状态机并通过轻量窗口消息发布结果，不执行渲染、IPC 或文件操作。

### 2.2 状态机与恢复

- `KeyIdentity` 使用扫描码、扩展位和修饰键掩码匹配。
- 同一物理键保持按下时忽略重复 KeyDown。
- 捕获事件与轮询状态只有全部释放后才产生合并 KeyUp。
- Hold 的 KeyUp 按物理键释放，因此先松开修饰键不会导致 Hold 卡住。
- Raw Input 设备移除、WTS 会话变化和 Input 线程关闭会清空已按键并释放活动 Hold。
- 新配置成功应用后恢复配置中的 A/B 初始状态，并重新计算 `SwitchA`、`SwitchB`、`Both` 或 `Either` 可见性。

### 2.3 配置热重载与失败处理

- `ApplySnapshot` 在推进 IPC 配置版本前解析并应用 `switches`。
- 非法输入配置返回 `InvalidInputConfiguration`，系统热键注册失败返回 `InputRegistrationFailed`。
- 注册失败信息包含扫描码、扩展位、修饰键掩码和 Win32 错误号。
- 新 `RegisterHotKey` 计划失败时恢复旧计划；回滚本身失败时清理全部系统热键并将输入状态标记为未配置。
- 验证或注册失败不会推进 Host 的配置版本；相同版本和内容的幂等重放不会重复应用配置。
- 第一份有效 IPC 配置到达前，覆盖层保持原型既有可见行为；之后显示器选择结果与逻辑开关可见性共同决定覆盖窗口是否显示。

### 2.4 冲突和保留键校验

Core 与 Host 均拒绝：

- 与激活模式无关或缺失的按键字段；
- A/B 开关有效动作之间重复的完整 `KeyIdentity`；
- 含 Win 修饰键的组合；
- 左右 Windows 主键；
- Alt+Tab、Alt+Esc、Ctrl+Esc、Ctrl+Alt+Delete；
- F12 调试器保留键；
- 无法转换为系统虚拟键的 `RegisterHotKey` 组合。
